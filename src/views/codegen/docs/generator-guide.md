# 代码生成器配置指南

字段配置是代码生成的核心环节，本指南汇总了字段命名规则、表单类型限制与验证配置技巧。

---

## 一、字段命名规则（自动默认/强制）

系统会根据**数据库列名**自动推断表单类型，配置时无需手动填写，但可手动调整（用户字段除外）。

| 列名规则 | 默认表单类型 | 说明 |
|---|---|---|
| `xxx_time` 结尾（如 `create_time`） | 日期时间框 | 自动默认 |
| `xxx_date` 结尾（如 `birth_date`） | 日期框 | 自动默认 |
| `user_id` / `create_by` / `update_by` | 用户选一 | **强制**，不可修改 |
| `xxx_id` 结尾（如 `parent_id`） | 多对一（可选） | 允许配置为多对一 |

> 技巧：列名以 `_id` 结尾的字段（外键），可配置为**多对一**，用于关联其他表；`parent_id` 等自关联外键同样适用。

## 二、字段类型限制规则

选择不同表单类型后，**验证列**会展示对应的限制配置：

| 表单类型 | 验证列展示 | 配置内容 |
|---|---|---|
| 数字输入框 | 最小值 `~` 最大值 | 数值范围控制 |
| 日期框 | 开始日期 `~` 结束日期 | 日期范围（`YYYY-MM-DD`） |
| 日期时间框 | 开始时间 `~` 结束时间 | 时间范围（`YYYY-MM-DD HH:mm:ss`） |
| 输入框 | 校验类型下拉 | 手机号 / 邮箱 / 网址 / 全数字 / 全英文 / 汉字 |
| 多对一 | 关联表下拉 | 从当前表列表中选择关联目标表 |
| 用户选一 | 固定提示 | 关联用户表，无需配置 |

> 技巧：输入框选择校验类型后，生成的表单会自动带上对应正则校验，无需手写。

## 三、外键字段（多对一）配置

- 仅列名以 `_id` 结尾的字段允许配置为**多对一**，其他字段该选项禁用。
- 配置为多对一后，在验证列选择**关联的目标表**（值为表名，标签为"表描述(表名)"）。
- 多对一字段**不可**配置为日期框 / 日期时间框。

## 四、用户字段（用户选一）

- 列名 `user_id`、`create_by`、`update_by` 会**强制**使用"用户选一"类型。
- 这类字段固定关联用户表，验证列显示"关联用户表"提示，无需额外配置。

## 五、查询配置技巧

- **查询列**：勾选后字段进入查询条件；未勾选时查询方式下拉不可用。
- **查询方式**：支持 `=`、`LIKE`、`IN`、`BETWEEN`、`>`、`>=`、`<`、`<=`、`!=` 等。
- 日期类型字段默认使用 `BETWEEN`（范围查询），符合直觉。
- 批量操作：点击"查询 / 列表 / 表单"按钮可一键全选或全不选。

## 六、列表与表单展示

| 列 | 含义 |
|---|---|
| 列表 | 勾选后字段显示在列表页 |
| 表单 | 勾选后字段显示在表单页（必填开关在此生效） |
| 必填 | 仅当"表单"勾选时可开启 |

> 技巧：主键、逻辑删除等内部字段建议关闭"列表 / 表单 / 查询"，只保留隐藏域。

## 七、其他配置

- **主包名**：默认 `com.youlai.vadmin`，按项目实际调整。
- **移除表前缀**：如 `sys_`，生成实体时会自动去掉前缀。
- **实体名**：根据表名自动推导，去掉前缀并转驼峰。
- **上级菜单**：生成代码后会自动创建对应菜单，需分配权限给角色才能显示。
- **数据库类型**：`VITE_API_TYPE` 为 `POSTGRES` 时，表列表不显示"存储引擎"列。
